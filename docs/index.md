# crypto-backend

NAYFT crypto backend API — Node.js, TypeScript, Express, and MongoDB service powering
authentication, the social graph, news/content, market data, portfolio tracking, the
Portfolio Intelligence engine, risk scoring, sentiment, and notifications for the NAYFT
apps (including [crypto-market](../crypto-market)).

See the **API** tab on this entity's catalog page for the full OpenAPI reference
(`openapi/crypto-backend-v1.yaml`), or browse the guides below.
